# Maquete 3D do terreno 12 × 40

Maquete interativa em Three.js: fachada recuada, garagem coberta, área gourmet, lounge, academia e quintal.

Abra `index.html` no navegador, ou acesse a página publicada pelo GitHub Pages.

Controles: arraste para girar, role para aproximar. Os botões "Câmera livre" e "Passear a pé" permitem andar pela maquete.
